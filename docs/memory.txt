# TIRO Workshop — Memory System v0.2

Current status:

* Landing page exists
* Manifesto page exists
* Memory Project page exists
* `/memories/demo` exists as a static Memory detail page
* Visual language is dark, restrained, archival, institutional, and elegant

Goal for this session:
Evolve the static memory detail page into a reusable Memory system prototype with media support, related nodes, and a browsable memory index.

Do not add a database yet.
Do not add auth yet.
Do not add upload flows yet.
Do not add external dependencies unless absolutely necessary.

## 1. Create a reusable Memory data model

Create a local mock data file, for example:

`src/data/memories.ts`

Define a TypeScript type/interface for `MemoryRecord`.

Suggested fields:

```ts
type MemoryMedia = {
  type: "image" | "audio" | "video" | "none";
  src?: string;
  alt?: string;
  caption?: string;
  duration?: string;
  credit?: string;
};

type RelatedNode = {
  label: string;
  type: "Person" | "Place" | "Theme" | "Institution" | "Language";
  href?: string;
};

type MemoryRecord = {
  id: string;
  title: string;
  summary: string;
  location: string;
  language: string;
  era: string;
  contributor: string;
  consentStatus: string;
  provenance: string;
  rightsUsage: string;
  sensitivity?: string;
  media: MemoryMedia;
  transcript: string;
  culturalContext: string;
  tags: string[];
  relatedNodes: RelatedNode[];
  relatedMemories: {
    title: string;
    summary: string;
    href: string;
  }[];
};
```

Create at least 3 demo memory records:

* `lagos-port-harcourt-migration`
* `rain-season-enugu`
* `market-song-lagos`

The existing `/memories/demo` may redirect to or render the Lagos migration record.

## 2. Build a reusable MediaViewer component

Create:

`src/components/MemoryMediaViewer.tsx`

Requirements:

* If media type is `"image"`, render a large archival image frame.
* If media type is `"audio"`, render an HTML5 audio player inside a styled archival card.
* If media type is `"video"`, render an HTML5 video player with controls.
* If media type is `"none"`, render a restrained placeholder that says:
  “No public media attached to this record.”
* Always show caption and credit if available.
* Styling should match existing TIRO visual system.
* Use semantic HTML.
* Keep it accessible.
* Do not autoplay anything.

Placement:
On the Memory detail page, place the media viewer after Provenance/Consent and before Transcript.

Rationale:
The record should establish trust, provenance, and rights before inviting media consumption.

Each card should include:

The page should feel like the beginning of an archive, not a blog list.

Title:
“Memory Records”

Subtitle:
